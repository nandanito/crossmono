# 0007. User interface

- Status: Accepted
- Date: 2026-10-28

## Context

What CrossPoint does today on the PaperMono:

- **Rendering.** A 1-bit framebuffer with dithered greys. Render modes `BW`, `GRAYSCALE_LSB`, `GRAYSCALE_MSB`
  (`lib/GfxRenderer/GfxRenderer.h:37`). Text anti-aliasing is on by default (`textAntiAliasing = 1`,
  `src/CrossPointSettings.h:298`). Reader fonts are 2-bit, UI fonts 1-bit.
- **Refresh.** Fast refresh by default, a half refresh every N pages (`refreshFrequency = REFRESH_15`,
  `src/CrossPointSettings.h:331`), a full refresh on sleep.
- **Panel.** The SSD1677 is sold as a 4-grey panel, but the SDK driver offers 3-level overlay grey only. M5Stack's
  measured timings: quality 4.71 s, text 0.45 s, fast 0.34 s, fastest 0.07 s. M5Stack recommends a full refresh
  after about 10 partial ones.
- **Themes.** `CLASSIC`, `LYRA`, `LYRA_3_COVERS`, `ROUNDEDRAFF`, `COVER_GRID` (`src/CrossPointSettings.h:205`,
  `src/components/UITheme.cpp:40-61`). Upstream has frozen new themes and wants to move themes to the SD card
  (`SCOPE.md:34,79-84`).
- **Touch navigation.** No on-screen Home button. Back is the header back button or a left-edge swipe; Home is a
  bottom-edge swipe up, handled for every non-Home activity (`src/activities/ActivityManager.cpp:120-126`); a
  top-edge swipe or a status-bar tap opens the frontlight Control Center; a tap in the centre third opens the
  reader menu; the reader menu has Go Home (`src/activities/reader/EpubReaderMenuActivity.cpp:97`). New users do
  not discover these gestures, and some screens can only be left by gesture.
- **SDK components.** FreeInk UI ships `gesture-bar`, `tap-zones` and `reader-chrome`
  (`freeink-sdk/libs/ui/FreeInkUI/include/components/bars/`). CrossPoint does not use them.

## Options considered

1. **Keep CrossPoint's UI unchanged.** No work, but hidden gestures stay hidden, and nothing tells a user they are
   running CrossMono.
2. **Grey UI everywhere.** Looks richer, but every screen change becomes a slower grey refresh with more ghosting.
3. **1-bit fast UI with anti-aliased text, our own theme, and a visible navigation bar** (chosen). Fast and clear;
   grey only where it pays off.

## Decision

- The UI stays 1-bit and fast, with anti-aliased text.
- CrossMono gets its own theme, in our files.
- A visible touch navigation bar, based on the SDK's FreeInk UI `gesture-bar`.
- Grey only on hero surfaces: book covers, the sleep screen and About.
- 0.1.0 is branding only: boot logo, name, About, USB product strings and the web UI header. The theme and the
  navigation bar come in 0.3.0 ([docs/roadmap.md](../roadmap.md)).

## Consequences

- Our theme needs one registration seam in upstream's theme list (`UITheme.cpp`, `CrossPointSettings.h`). It is
  added to the seams table when it is written. If upstream moves themes to the SD card first, we use that instead.
- The navigation bar takes a strip of screen height from every screen. Its height is decided with the theme.
- Branding in 0.1.0 touches several upstream files (boot screen, logo, translations, About, web UI); all are in the
  seams table.
